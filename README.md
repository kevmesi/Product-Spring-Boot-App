# Product REST Service

A small REST service for managing a list of products. Prices are stored in EUR, and the
USD price is derived on creation from the daily exchange rate published by the
[Croatian National Bank (HNB) API](https://api.hnb.hr/tecajn-eur/v3?valuta=USD).

## Tech stack

|             |                                                  |
|-------------|--------------------------------------------------|
| Language    | Java 21                                          |
| Build       | Maven (wrapper included)                         |
| Framework   | Spring Boot 4.1.0, Spring MVC                    |
| Persistence | Spring Data JPA / Hibernate                      |
| Database    | PostgreSQL 16                                    |
| Testing     | JUnit 5, Mockito, MockMvc, MockRestServiceServer |

## Prerequisites

- **JDK 21 or newer** — `java -version`
- **Docker** — used to run PostgreSQL locally
- **Internet access** — creating a product calls the HNB API to convert EUR to USD

## Setup

### 1. Clone

```bash
git clone <repository-url>
cd Product-Spring-Boot-App
```

### 2. Start PostgreSQL

```bash
docker compose up -d
```

This starts Postgres 16 on `localhost:5432` with database `mydatabase`, user `postgres`,
password `user` — matching `demo/src/main/resources/application.properties`.

Confirm it is accepting connections:

```bash
docker compose ps
```

If you would rather use an existing local Postgres instance, skip this step and update the
connection settings in `application.properties` instead.

### 3. Run the application

```bash
cd demo
./mvnw spring-boot:run
```

On Windows use `mvnw.cmd spring-boot:run`.

Info: If "Permission denied" error shows, run `chmod +x mvnw` in the `demo` directory.

The service starts on <http://localhost:8080>.

### 5. Stopping

```bash
docker compose down          # stop Postgres, keep data
docker compose down -v       # stop Postgres and delete the data volume
```

## Configuration

Settings live in `demo/src/main/resources/application.properties`.

| Property                     | Default                                       |
|------------------------------|-----------------------------------------------|
| `spring.datasource.url`      | `jdbc:postgresql://localhost:5432/mydatabase` |
| `spring.datasource.username` | `postgres`                                    |
| `spring.datasource.password` | `user`                                        |
| `hnb.api.url`                | `https://api.hnb.hr/tecajn-eur/v3`            |
| `server.port`                | `8080`                                        |

## API

Base path: `/api/products`

| Method | Path                      | Description                                | Success       |
|--------|---------------------------|--------------------------------------------|---------------|
| `POST` | `/api/products`           | Create a product                           | `201 Created` |
| `GET`  | `/api/products`           | List all products                          | `200 OK`      |
| `GET`  | `/api/products/{code}`    | Get one product by its code                | `200 OK`      |
| `GET`  | `/api/products/available` | List products where `is_available` is true | `200 OK`      |

### Product

| Field          | Type    | Constraints                                                             |
|----------------|---------|-------------------------------------------------------------------------|
| `id`           | integer | Generated by the database                                               |
| `code`         | string  | Required, unique, exactly 10 alphanumeric characters                    |
| `name`         | string  | —                                                                       |
| `price_eur`    | decimal | Required, `>= 0`                                                        |
| `price_usd`    | decimal | `>= 0`, calculated from `price_eur` on creation — not accepted as input |
| `is_available` | boolean | —                                                                       |

### Create a product

```bash
curl -i -X POST http://localhost:8080/api/products \
  -H 'Content-Type: application/json' \
  -d '{
        "code": "ABCD123456",
        "name": "Example product",
        "price_eur": 99.99,
        "is_available": true
      }'
```

```json
{
  "id": 1,
  "code": "ABCD123456",
  "name": "Example product",
  "price_eur": 99.99,
  "price_usd": 116.32,
  "is_available": true
}
```

`price_usd` is calculated server-side; any value supplied in the request body is ignored.

### Retrieve products

```bash
curl http://localhost:8080/api/products
curl http://localhost:8080/api/products/ABCD123456
curl http://localhost:8080/api/products/available
```

### Errors

| Status            | When                                                                                 |
|-------------------|--------------------------------------------------------------------------------------|
| `400 Bad Request` | Validation failed — e.g. `code` is not exactly 10 characters, or a price is negative |
| `404 Not Found`   | No product exists for the requested code                                             |

## Tests

```bash
cd demo
./mvnw test
```

Unit tests cover the service, controller and currency-conversion layers. The HNB response is
stubbed with `MockRestServiceServer`, so the suite runs offline and needs neither a running
database nor internet access.

## Notes

- The schema is created manually in step 3. A migration tool such as Flyway would be the
  natural next step, so the schema is versioned alongside the code.
- `price_usd` is calculated once at creation time using that day's HNB rate, and is not
  recalculated afterwards.
